# ផ្ទះម៉ាក់រចនា (Pteah Mak Rachana) - Khmer Kitchen & Multi-Frame Web Portal

គេហទំព័រ Web Application **«ផ្ទះម៉ាក់រចនា»** ដ៏ទំនើប ស្រស់ស្អាតឥតខ្ចោះ បង្កើតឡើងដោយ Single Page Architecture (SPA) ជាមួយ HTML5, CSS3, និង Vanilla JavaScript (ES6+) ជាភាសាខ្មែរ ១០០% ស្របតាមស្តង់ដារវចនានុក្រមសម្តេចព្រះសង្ឃរាជ ជួន ណាត ដោយប្រើប្រាស់ពុម្ពអក្សរខ្មែរ **DaunPenh** គាំទ្រទាំងទម្រង់ពន្លឺ (Light Mode) និងទម្រង់ងងឹត (Dark Mode)។

## 🌟 រចនាសម្ព័ន្ធទំព័រ និងមុខងារតាមសំណើចុងក្រោយ

  - ផលិតផលសម្រស់ធម្មជាតិ
  - ព័ត៌មានជាតិ-អន្តរជាតិនាពេលបច្ចុប្បន្នពី RFI និង Hot News

- **ផ្ទាំង Admin Post Creator (រចនាបថដូច Facebook):** មានប្រអប់ *«តើលោកអ្នកចង់បង្ហោះលក់ ឬចែករំលែកអ្វីថ្ងៃនេះ?»* ជាមួយប៊ូតុងរហ័ស 🍲 ម្ហូប, ✨ សម្រស់, 📰 ព័ត៌មាន, 🩺 សុខភាព, 🏃‍♂️ កីឡា។

   - **Page គឺនិយាយតែព័ត៌មានមួយគត់** ពី RFI ខេមរភាសា និង Hot News សង្គម/សេដ្ឋកិច្ច ដោយមិនលាយឡំមុខម្ហូប ឬផលិតផលផ្សេងឡើយ។
2. **🍲 ចុចលើ Button «មុខម្ហូប»៖**
   - បង្ហាញ Page ដាច់ដោយឡែកដែលមានចំណងជើងធំចំកណ្តាលថា **«សូមជ្រើសរើសម្ហូបសម្រាប់ថ្ងៃនេះ»**
   - និយាយតែមុខម្ហូបខ្មែរឆ្ងាញ់ៗ ពិសេសមុខម្ហូបហត្ថលេខាទាំង ៤ មុខ (`1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`) ជាមួយប៊ូតុងកម្ម៉ង់ផ្ទាល់តាម Telegram & Messenger។

   - បង្ហាញ Page ដាច់ដោយឡែកដែលមានចំណងជើងធំចំកណ្តាលថា **«ផលិតផលសម្រស់ធម្មជាតិ»**
   - និយាយតែផលិតផលថែរក្សាសម្រស់បែបធម្មជាតិ សុវត្ថិភាពខ្ពស់។

   - និយាយតែគន្លឹះសុខភាព ការការពារជំងឺ និងការណែនាំពីក្រសួងសុខាភិបាល (MoH)។
