គេហទំព័រ Web Application **«ផ្ទះម៉ាក់រចនា»** ដ៏ទំនើប ស្រស់ស្អាតឥតខ្ចោះ បង្កើតឡើងដោយ Single Page Architecture (SPA) ជាមួយ HTML5, CSS3, និង Vanilla JavaScript (ES6+) ជាភាសាខ្មែរ ១០០% ស្របតាមស្តង់ដារវចនានុក្រមសម្តេចព្រះសង្ឃរាជ ជួន ណាត ដោយប្រើប្រាស់ Logo ផ្លូវការថ្មី **LGR1.jpg** និងពុម្ពអក្សរខ្មែរ **DaunPenh** គាំទ្រទាំងទម្រង់ពន្លឺ (Light Mode) និងទម្រង់ងងឹត (Dark Mode)។
