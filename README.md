# ផ្ទះម៉ាក់រចនា (Pteah Mak Rachana) - Khmer Kitchen & Multi-Frame Web Portal

គេហទំព័រ Web Application **«ផ្ទះម៉ាក់រចនា»** ដ៏ទំនើប ស្រស់ស្អាតឥតខ្ចោះ បង្កើតឡើងដោយ Single Page Architecture (SPA) ជាមួយ HTML5, CSS3, និង Vanilla JavaScript (ES6+) ជាភាសាខ្មែរ ១០០% ស្របតាមស្តង់ដារវចនានុក្រមសម្តេចព្រះសង្ឃរាជ ជួន ណាត ដោយប្រើប្រាស់ Logo ផ្លូវការថ្មី **LGR1.jpg** និងពុម្ពអក្សរខ្មែរ **DaunPenh** គាំទ្រទាំងទម្រង់ពន្លឺ (Light Mode) និងទម្រង់ងងឹត (Dark Mode)។

### ១. ទំព័រដើម (Page Home) ➔ «ផ្ទះម៉ាក់រចនា សូមស្វាគមន៍» & គោលការណ៍ចម្បង ៣ យ៉ាង

នៅផ្នែកខាងលើនៃទំព័រដើម ក្រោមចំណងជើងធំ **«ផ្ទះម៉ាក់រចនា សូមស្វាគមន៍»** ត្រូវបានរំលេចដោយខ្លឹមសារយ៉ាងកក់ក្តៅ និងគោលការណ៍ចម្បង ៣ យ៉ាង៖
> **«ផ្ទះម៉ាក់រចនា គឺជាទីតាំងដ៏កក់ក្តៅ និងជាជម្រើសដ៏ស័ក្តិសមបំផុតសម្រាប់គ្រប់ក្រុមគ្រួសារ និងអ្នកស្រឡាញ់សុខភាព ដោយឈរលើគោលការណ៍ចម្បង ៣ យ៉ាង៖»**
1. ⭐ **ឱជារសដើមបែបខ្មែរពិតៗ៖** គ្រប់មុខម្ហូបប្រចាំហាង ត្រូវបានចម្អិនផ្ចិតផ្ចង់តាមរូបមន្តប្រពៃណីដូនតាខ្មែរ រសជាតិមុតស្រាលល្មម ចូលជាតិសព្វ មិនផ្អែមខ្លាំង មិនប្រៃខ្លាំង ផ្ដល់នូវភាពឆ្ងាញ់ជក់មាត់ដូចស្នាដៃម្ដាយធ្វើឱ្យញ៉ាំនៅផ្ទះ។
2. ⭐ **ស្តង់ដារអនាម័យខ្ពស់៖** បរិស្ថានចម្អិន និងឧបករណ៍ប្រើប្រាស់ទាំងអស់ត្រូវបានសម្អាត និងសម្លាប់មេរោគយ៉ាងម៉ត់ចត់។ គ្រឿងផ្សំគ្រប់មុខ រួមមានបន្លែស្រស់ សាច់ និងគ្រឿងទេស ត្រូវបានលាងសម្អាតតាមក្បួនសុវត្ថិភាពម្ហូបអាហារ ចម្អិនថ្មីៗក្តៅៗហុយ។
3. ⭐ **អាហារូបត្ថម្ភ និងសុខុមាលភាព៖** ផ្តោតលើសុខភាពអ្នកទទួលទានជាចម្បង ដោយជ្រើសរើសប្រើប្រាស់បន្លែធម្មជាតិសម្បូរជាតិសរសៃ កាត់បន្ថយជាតិខ្លាញ់កក គ្មានការប្រើប្រាស់សារធាតុរក្សាទុក និងផ្ដល់តុល្យភាពកាឡូរីត្រឹមត្រូវ ស័ក្តិសមសម្រាប់មនុស្សគ្រប់វ័យ ជាពិសេសមនុស្សវ័យកណ្តាល និងមនុស្សចាស់។

- **ការកែសម្រួលបន្ថែមលើ Hero Card:**
  - ដកចេញប៊ូតុងទាំងពីរ (មើលមុខម្ហូបថ្ងៃនេះ និង គន្លឹះសុខភាពចំណីអាហារ)។
  - ដកចេញប្រអប់ ២៤/៧ ដោយរក្សាទុកតែប្រអប់ស្ថិតិសំខាន់ពីរគឺ៖ `១០០% គ្រឿងផ្សំខ្មែរស្រស់ៗ` និង `០% គ្មានសារធាតុរក្សាទុក`។

### ៤. សញ្ញាចុច ៣ (•••) គ្រប់គ្រង Post សម្រាប់តែ Admin ប៉ុណ្ណោះ
- នៅលើផ្នែកខាងស្តាំនៃ Post នីមួយៗ មានប៊ូតុងចុច ៣ `•••`៖
  - **សម្រាប់ Admin តែប៉ុណ្ណោះ៖** ពេលចុចលើសញ្ញា ៣ ចុច វានឹងទម្លាក់ Menu ចំនួន ២ មុខងារ៖
    1. **✏️ កែតម្លៃ (Edit Price)៖** បើកផ្ទាំង Dialog ឱ្យ Admin វាយតម្លៃថ្មីជាប្រាក់រៀល ឬដុល្លារ ដោយមានប្រព័ន្ធគណនាអត្រាប្តូរប្រាក់ស្វ័យប្រវត្តិ ($1 = 4,080 ៛) រួចរក្សាទុក និង Update លើអេក្រង់ភ្លាមៗ!
