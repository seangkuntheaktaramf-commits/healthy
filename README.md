# ផ្ទះម៉ាក់រចនា (Pteah Mak Rachana) - Khmer Kitchen & Online E-Commerce System

គេហទំព័រ Web Application **«ផ្ទះម៉ាក់រចនា»** ដ៏ទំនើប ស្រស់ស្អាតឥតខ្ចោះ បង្កើតឡើងដោយ Single Page Architecture (SPA) ជាមួយ HTML5, CSS3, និង Vanilla JavaScript (ES6+) ជាភាសាខ្មែរ ១០០% ស្របតាមស្តង់ដារវចនានុក្រមសម្តេចព្រះសង្ឃរាជ ជួន ណាត ដោយប្រើប្រាស់ពុម្ពអក្សរខ្មែរ **DaunPenh** គាំទ្រទាំងទម្រង់ពន្លឺ (Light Mode) និងទម្រង់ងងឹត (Dark Mode)។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

### ១. រចនាសម្ព័ន្ធបែងចែកជាពីរ Frame (Two-Frame Architecture)
- **Frame 1 (ខាងលើ - Top Fixed Header & Navigation):**
  - **Logo & ឈ្មោះ Page:** បង្ហាញ Logo ផ្លូវការ `mak_rachana_logo.jpg` ជាមួយឈ្មោះ **«ផ្ទះម៉ាក់រចនា»** និងអក្សរខាងក្រោម **«ម្ហូបខ្មែររសជាតិដើម»** តែមួយគត់។
  - **Menu ទាំង ៦ នៅផ្នែកខាងឆ្វេង (Menu Left Group):**
    1. 🏠 **ទំព័រដើម:** Symbol រូបផ្ទះតូចមួយ មានមុខងារត្រឡប់ទៅ Page ដើមវិញ។
    2. 🌐 **ព័ត៌មាន:** Symbol រូបផែនដីតូចមួយ បើក Page ព័ត៌មានដែលមានចំណងជើងធំ **«ព័ត៌មាន»** (និយាយតែព័ត៌មានសុទ្ធសាធពី RFI និង Hot News)។
    3. 🍲 **មុខម្ហូប:** Symbol រូបចានហ៊ុយៗតូចមួយ បើក Page មុខម្ហូបដែលមានចំណងជើងធំ **«សូមជ្រើសរើសម្ហូបសម្រាប់ថ្ងៃនេះ»**។
    4. ✨ **ផលិតផលសម្រស់:** Symbol រូបផ្កាយ/សម្រស់ បើក Page ផលិតផលសម្រស់ដែលមានចំណងជើងធំ **«ផលិតផលសម្រស់ធម្មជាតិ»**។
    5. 🩺 **សុខភាព:** Symbol រូបពេទ្យ/សុខភាព បើក Page សុខភាពដែលមានចំណងជើងធំ **«សុខភាព និង អនាម័យ»**។
    6. 🏃‍♂️ **កីឡា:** Symbol រូបកីឡា បើក Page កីឡាដែលមានចំណងជើងធំ **«កីឡាដើម្បីសុខភាព»**។
  - **ផ្នែកខាងស្តាំនៃ Menu Bar បន្ទាប់ពី Menu កីឡា (Menu Right Group):**
    - **ប្រអប់ហាងឆេង មាស និង ហាងឆេងដុល្លារ:** បង្ហាញតម្លៃមាស និងអត្រាប្តូរប្រាក់ផ្ទាល់ (`🥇 មាស $3,140/តម្លឹង | 💵 $1 = 4,080៛`) ចុចលើប្រអប់នេះដើម្បីចូលមើលតារាងលម្អិត និងម៉ាស៊ីនគណនាប្រាក់ KHR ➔ USD។
    - **ប៊ូតុងពន្លឺ (Light/Dark Mode):** ស្ថិតនៅខាងស្តាំបន្ទាប់ពីប្រអប់ហាងឆេង មានមុខងារ **«បិទពន្លឺ»** (Dark Mode 🌙) និង **«បើកពន្លឺ»** (Light Mode ☀️) ដំណើរការយ៉ាងរលូន។
- **Frame 2 (ខាងក្រោម - Bottom Dynamic Content):**
  - ផ្ទុកមាតិកានៃ Page នីមួយៗតាមការចុច Menu ក្នុង Frame ទី១ ដោយ Frame 1 នៅតែបង្ហាញជាប់ខាងលើជានិច្ច មិនរំកិលបាត់ឡើយ!

### ២. ប្លង់ទំព័រ និងចំណងជើងតាមស្តង់ដារ (Exact Page Headings)
- **ទំព័រដើម (Page Home):** ចំណងជើងស្វាគមន៍ធំ **«ផ្ទះម៉ាក់រចនា សូមស្វាគមន៍»** (ទំហំអក្សរធំជាងមុន ១លេខ) ព្រមទាំង Feed ម្ហូប, Story bar, ផ្ទាំង Fast Order, និង Quick Navigation Cards។
- **ទំព័រព័ត៌មាន (Page News):** ចំណងជើងធំ **«ព័ត៌មាន»** និយាយតែព័ត៌មានមួយគត់ពី RFI ខេមរភាសា និងព្រឹត្តិការណ៍សង្គម/សេដ្ឋកិច្ចប្រចាំថ្ងៃ។
- **ទំព័រមុខម្ហូប (Page Food):** ចំណងជើងធំ **«សូមជ្រើសរើសម្ហូបសម្រាប់ថ្ងៃនេះ»** រៀបរាប់បញ្ជីមុខម្ហូបខ្មែរឆ្ងាញ់ៗ ពិសេសមុខម្ហូបប្រចាំហាង **«ម្ជូរគ្រឿងសាច់ រសជាតិដើម» (រូបភាព `1.jpg`)** ជាមួយចំណុចលេចធ្លោ ៣ យ៉ាង៖
  - ⭐ **សាច់គោស្រស់គុណភាពខ្ពស់៖** ជ្រើសរើសសាច់គោជាប់ខ្លាញ់ផុយទន់ល្មម រម្ងាស់ចូលជាតិយ៉ាងល្អ គ្មានក្លិនឆ្អាប ផ្តល់ជាតិប្រូតេអ៊ីន និងថាមពលពេញលេញ។
  - ⭐ **គ្រឿងបុកស្រស់ៗពីធម្មជាតិ៖** ផ្សំពីស្លឹកគ្រៃ រមៀត រំដេង ខ្ទឹមស និងស្លឹកក្រូចសើច ដែលសម្បូរដោយសារធាតុប្រឆាំងអុកស៊ីតកម្ម ជួយសម្រួលការរំលាយអាហារ និងបង្កើនប្រព័ន្ធការពាររាងកាយ។
  - ⭐ **រសជាតិឆ្ងាញ់ អនាម័យខ្ពស់៖** ជូរអែមមុតស្រាលស្រទន់ ក្រអូបឈ្ងុយគ្រឿងបុកខ្មែរ ចម្អិនថ្មីៗក្តៅៗតាមស្តង់ដារអនាម័យត្រឹមត្រូវ គ្មានបារម្ភរឿងសុខភាព។
- **ទំព័រផលិតផលសម្រស់ (Page Beauty):** ចំណងជើងធំ **«ផលិតផលសម្រស់ធម្មជាតិ»** បង្ហាញផលិតផលថែរក្សាសម្រស់បែបធម្មជាតិ សុវត្ថិភាពខ្ពស់។
- **ទំព័រសុខភាព (Page Health):** ចំណងជើងធំ **«សុខភាព និង អនាម័យ»** ផ្តល់នូវគន្លឹះសុខភាព ការការពារជំងឺ និងអាហារូបត្ថម្ភគ្រប់វ័យ។
- **ទំព័រកីឡា (Page Sports):** ចំណងជើងធំ **«កីឡាដើម្បីសុខភាព»** បង្ហាញក្បួនហាត់ប្រាណប្រចាំថ្ងៃ និងវិធីពង្រឹងកាយសម្បទា។

### ៣. ប្លង់រូបភាពដែល Post (ដូច Facebook) ជាមួយប៊ូតុងសកម្មភាព និង Order ផ្ទាល់
- **ស៊ុម គែម ព័ទ្ធជុំវិញ និងដាច់ៗពីគ្នា:**
  - កាត Post នីមួយៗមានស៊ុមគែមស្រស់ស្អាត (Card Border & Shadow) ឃ្លាតដាច់ពីគ្នា។
  - គំរូ Post បែប Collage រូបភាពចំនួន ៣ (រូបធំផ្ដេកខាងលើ + រូបតូចពីរចំហៀងគ្នានៅខាងក្រោម) ដូចក្នុងរូបភាពគំរូពិតប្រាកដ។
  - ចុចលើរូបភាពណាមួយដើម្បីពង្រីកមើលទំហំធំក្នុង Lightbox Modal។
- **ប៊ូតុងសកម្មភាពតូចៗចំនួន ៣ (គ្មានអក្សរបញ្ជាក់):**
  - 👍 ប៊ូតុងចូលចិត្ត (Like) ជាមួយ Counter ចំនួន Like
  - 💬 ប៊ូតុងបញ្ចេញមតិ (Comment) ជាមួយ Counter ចំនួនមតិ
  - ↗️ ប៊ូតុងចែករំលែក (Share) ជាមួយ Counter ចំនួន Share
- **សញ្ញាចុច ៣ តូចៗ (•••) នៅលើរូបភាពផ្នែកខាងស្តាំ:**
  - ចុចលើសញ្ញាចុច ៣ ដើម្បីបើក Option Dropdown (ចម្លងតំណភ្ជាប់, រាយការណ៍, រក្សាទុក)។
- **ប៊ូតុងកម្ម៉ង់ផ្ទាល់ (Order Directly):**
  - ប៊ូតុង Telegram ផ្ញើសារកម្ម៉ង់មុខម្ហូបទៅកាន់ម្ចាស់ផ្ទាល់
  - ប៊ូតុង Messenger ផ្ញើសារកម្ម៉ង់រហ័សទាន់ចិត្ត

### ៤. ប្រព័ន្ធប្តូរពន្លឺ និងងងឹត (Light & Dark Theme)
- គាំទ្រការប្តូររវាង **«បើកពន្លឺ (Light Mode)»** និង **«បិទពន្លឺ (Dark Mode)»** ដោយរលូន ជាមួយពណ៌កក់ក្តៅរចនាបថផ្ទះបាយខ្មែរ។
- រក្សាស្ថានភាព Theme ទុកក្នុង `localStorage` ស្វ័យប្រវត្ត មិនបាត់បង់ពេល Refresh ឡើយ។

## 🚀 របៀបបើកដំណើរការ (How to Run)

1. ចុច Double click លើ File:
   ```cmd
   d:\My_Folder_My_Software\Software_Factory_System\pteah_mak_rachana\run_server.bat
   ```
2. ឬបើក Browser (Chrome, Edge, Firefox) ហើយចូលទៅកាន់៖
   ```
   http://localhost:8080/
   ```
3. ឬបើក File `index.html` ផ្ទាល់ក្នុង Browser ក៏ដំណើរការបានពេញលេញដែរ។
