# ផ្ទះម៉ាក់រចនា (Pteah Mak Rachana) - Khmer Kitchen & Multi-Frame Web Portal

គេហទំព័រ Web Application **«ផ្ទះម៉ាក់រចនា»** ដ៏ទំនើប ស្រស់ស្អាតឥតខ្ចោះ បង្កើតឡើងដោយ Single Page Architecture (SPA) ជាមួយ HTML5, CSS3, និង Vanilla JavaScript (ES6+) ជាភាសាខ្មែរ ១០០% ស្របតាមស្តង់ដារវចនានុក្រមសម្តេចព្រះសង្ឃរាជ ជួន ណាត ដោយប្រើប្រាស់ Logo ផ្លូវការថ្មី **LGR1.jpg** និងពុម្ពអក្សរខ្មែរ **DaunPenh** គាំទ្រទាំងទម្រង់ពន្លឺ (Light Mode) និងទម្រង់ងងឹត (Dark Mode)។

### ២. ផលិតផលថ្មីក្នុង Menu «សាប៊ូកម្ចាត់អង្គែ» ➔ Haicneal (h9.png)
បានដាក់បញ្ចូលផលិតផលព្យាបាលស្បែកក្បាលជំនាញកម្រិតខ្ពស់ទៅក្នុងទំព័រ **«សាប៊ូកម្ចាត់អង្គែ»** និងទំព័រដើម៖

- **ឈ្មោះផលិតផល៖** `Haicneal (ឡេ/សាប៊ូកក់សក់ព្យាបាលអង្គែ និងរមាស់ស្បែកក្បាល)`
- **រូបភាពភ្ជាប់៖** `h9.png`
- **តម្លៃ៖** **$5.00** (២០,៤០០ ៛)
- **ចំណុចពិសេស និងអត្ថប្រយោជន៍គន្លឹះ៖**
  - ⭐ **ព្យាបាលបញ្ហាស្បែកក្បាល (Scalp Disorders)៖** ព្យាបាលជំងឺរលាកស្បែកក្បាលដោយសារមេរោគផ្សិត និងខ្លាញ់លើស (Seborrheic Dermatitis) ប្រកបដោយប្រសិទ្ធភាពខ្ពស់។
  - ⭐ **កម្ចាត់អង្គែដល់ឫសគល់ (Dedandruff)៖** កម្ចាត់អង្គែកម្រិតធ្ងន់ អង្គែរបកជាបន្ទះៗ និងការពារកុំឱ្យអង្គែត្រឡប់មកវិញ។
  - ⭐ **បំបាត់ការរមាស់ភ្លាមៗ (Antipruritus)៖** ជួយកាត់បន្ថយអាការរមាស់ ក្រហាយ និងសម្រួលស្បែកក្បាលឱ្យមានផាសុកភាព ត្រជាក់ស្រួល។
  - ⭐ **សមាសធាតុផ្សំ Compound Ketoconazole៖** សម្លាប់មេរោគផ្សិតស្បែកក្បាលយ៉ាងមានប្រសិទ្ធភាពខ្ពស់ ផ្ដល់ទំនុកចិត្ត និងសុវត្ថិភាពខ្ពស់បំផុត។

### ៥. សញ្ញាចុច ៣ (•••) គ្រប់គ្រង Post សម្រាប់តែ Admin ប៉ុណ្ណោះ
- នៅលើផ្នែកខាងស្តាំនៃ Post នីមួយៗ មានប៊ូតុងចុច ៣ `•••`៖
  - **សម្រាប់ Admin តែប៉ុណ្ណោះ៖** ពេលចុចលើសញ្ញា ៣ ចុច វានឹងទម្លាក់ Menu ចំនួន ២ មុខងារ៖
    1. **✏️ កែតម្លៃ (Edit Price)៖** បើកផ្ទាំង Dialog ឱ្យ Admin វាយតម្លៃថ្មីជាប្រាក់រៀល ឬដុល្លារ ដោយមានប្រព័ន្ធគណនាអត្រាប្តូរប្រាក់ស្វ័យប្រវត្តិ ($1 = 4,080 ៛) រួចរក្សាទុក និង Update លើអេក្រង់ភ្លាមៗ!
    2. **🗑️ លុប Post (Delete Post)៖** បង្ហាញផ្ទាំងបញ្ជាក់ (Confirm) មុននឹងលុបការបង្ហោះនោះចេញពីប្រព័ន្ធដោយសុវត្ថិភាព។
  - **សម្រាប់អ្នកប្រើប្រាស់ទូទៅ (Non-Admin / Guests)៖** ប្រព័ន្ធការពារសុវត្ថិភាពដោយមិនអនុញ្ញាតឱ្យកែប្រែ ឬលុបឡើយ។
